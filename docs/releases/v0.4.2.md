## 更新内容

- 新增剧集海报自动入库：下载任务保留资源站海报地址，后台按剧集下载图片，保存到剧目录和季目录，完成后通知 Emby 刷新。
- 旧版已完成任务自动从原站源详情补查海报，无需重新下载视频；同剧多集共用一次图片下载。
- 图片网络错误与视频下载状态分离，失败每五分钟重试；已有本地海报、其他剧集和分集文件保持原样。
- 图片校验实际 JPEG/PNG 格式、完整性、8 MiB 大小和 1600 万像素限制，采用临时文件同步和不覆盖发布，避免 Emby 读到不完整图片。
- 补图与删除任务协调，删除后不会由后台写回海报；关闭服务会取消未完成图片请求。
- 补充海报目录、重试策略和 Emby 媒体库封面的使用说明。

## 构建与升级

GitHub Actions 在推送本版本标签后执行竞态测试、静态检查和 JavaScript 语法检查，构建 Linux amd64、arm64 程序并生成 `SHA256SUMS`；上传后重新下载校验，成功才公开 Release。

已有部署可通过管理页面检测更新，或执行 `./scripts/moviehub-service.sh update`。升级会重启服务，JSON 数据和已有媒体保留。海报在后台补齐，原站源失效或缺少受支持图片时可自行放置本地海报；Emby 媒体库入口封面的生成结果与时间由 Emby 决定。
