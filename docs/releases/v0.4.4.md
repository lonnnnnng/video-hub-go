## 更新内容

- 下载队列支持勾选多个任务、全选当前筛选和清空选择。选择在自动刷新后保留，新增任务不会自动选中；手动修改搜索或状态筛选时清空选择。
- 支持批量暂停、继续与重试。按钮显示选中任务中可处理的数量，只操作状态适用的任务，逐项显示成功或失败结果。
- 支持批量删除。确认框列出本次固定任务清单，默认只删除记录并保留文件；勾选后可同时清理本集 MP4、分集 NFO、入库收据和临时分片。
- 批量删除沿用单项任务的停止下载、等待 worker 退出和文件归属核验。失败项保留记录和原因，可单独重试；某项失败不阻止其他任务，处理期间禁用重复操作。
- 批量工具栏适配桌面与窄屏，自动刷新后恢复正在使用的任务复选框焦点。

## 构建与升级

GitHub Actions 在推送本版本标签后执行竞态测试、静态检查和 JavaScript 语法检查，构建 Linux amd64、arm64 程序并生成 `SHA256SUMS`；上传后重新下载核验，成功才公开 Release。

已有部署可通过管理页面检测更新，或在服务器运行目录执行 `./moviehub-service.sh update`。升级前备份数据与媒体；升级会重启服务，保留原有任务、站源、JSON 配置和正式媒体文件。

升级后重新加载下载队列页面即可使用批量管理。删除确认框默认保留文件，只有明确勾选才会清理本集文件；共享剧集元数据和其他集的文件会保留。
