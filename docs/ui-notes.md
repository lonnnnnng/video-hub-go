# 管理台界面方向

用户管理自己的剧集收藏，主线是找到剧、勾选集、查看下载、等待入库。采用“片单 + 工作队列”布局，搜索页以海报呈现剧目，下载页采用明确的任务行，不增加与操作无关的统计卡片。

配色：纸白 #f6f8fc、墨蓝 #172b4d、浅蓝 #e9eff9、动作蓝 #245bda、成功绿 #187a59、告警红 #b53f43。
字体：系统中文 PingFang SC，英文 Avenir Next，标题 30px，正文 15px，辅助文字 13px。左对齐，主要内容宽度不超过 1200px。

布局：桌面左侧窄导航，右侧搜索工具和片单；手机导航横向滚动，单列任务行。详情使用最大 1180px 的原生 dialog：桌面左侧播放器、右侧分集，手机按播放器、分集、操作区纵向排列。点击集名播放，勾选复选框下载；保留追更与批量下载。线路自动选择，季号从已有追更或剧名获取，不再展示线路和季号输入控件。播放器交互拆分在 detail.js，仅首页与追更页加载 HLS.js。

审视：避免通用仪表盘的巨型数字、渐变和重复卡片；视觉重心留给影片海报，进度条只出现在实际任务上。空态直接说明下一步操作，失败显示可重试动作。

播放：直接把详情中的 episode.url 交给浏览器播放器，片单、分片和密钥由客户端获取。服务端不建立播放会话、不转发媒体，也不在直连失败后自动转发；弹框显示直连失败提示，供用户重试或更换站源。

下载队列：独立 jobs.js 负责队列操作与弹框。已完成任务用原生 video 通过任务 ID 对应的 HTTP MP4 接口播放。删除弹框默认保留文件，用户勾选后才清理本集产物与临时分片；等待 worker 退出再处理文件，失败保留记录和错误原因。

资源站：桌面三列、平板两列、手机一列；站名与域名保留文字，检测结果、默认站源及操作用 SVG 图标，配 title 和 aria-label；请求头设置入口和更新接口已移除，原有存储中的请求头仅用于兼容既有站源请求。
