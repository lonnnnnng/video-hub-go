## 更新内容

- 下载队列在桌面每行显示 3 条任务，窄屏逐级切换为两列、单列，减少横向留白。
- 已完成任务显示精确到秒的完成时间，取最终 MP4 的修改时间；旧任务在启动时自动补齐。
- 发布与崩溃恢复统一保留 MP4 合成时间，重启服务不会变成新的完成时间。
- 新增 GitHub Actions 发版流水线：仅推送正式版本标签时触发，普通代码推送不触发发版。

## 构建与升级

流水线执行 Go 竞态测试、静态检查和 JavaScript 语法检查，构建 Linux amd64、arm64 程序并生成 SHA256SUMS。上传后重新下载校验，成功后公开 Release。

已有部署可通过管理页面检测更新，或执行 `./scripts/moviehub-service.sh update`。升级会重启服务，JSON 数据和已有媒体保留。
