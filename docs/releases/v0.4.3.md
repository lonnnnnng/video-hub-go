## 更新内容

- 下载任务支持换线路重试与手动校正季号（1–999）。影片详情中的线路和季号用于新下载及追更；等待任务可调整配置，暂停、失败或取消任务可从最新站源详情明确选择对应分集并重试。
- 调整保留任务 ID，重置尝试次数、退避、进度和错误。任务正在运行、调整窗口已过期、原位置或目标位置已有媒体与发布记录、同季同集已有任务时拒绝修改，保护已有文件。
- 下载、分片写入与 MP4 封装检查磁盘空间，默认保留 2 GiB 安全余量，封装前另计成品所需空间。空间不足时等待并自动重查，不占下载名额、不消耗尝试次数。
- 正式 MP4、NFO 和入库收据完整发布且哈希匹配后自动清理临时分片，兼容旧版已完成任务；校验异常时保留临时文件并提示原因，下载页也可安排后台清理。
- 下载状态区分“已下载”与“Emby 已识别”。后台只有确认路径匹配且媒体源协议为 `File` 时才标记入库，扫描期间等待并定期复查；异常与超过 10 分钟仍未识别的任务提示检查媒体库、权限或补扫。

## 构建与升级

GitHub Actions 在推送本版本标签后执行竞态测试、静态检查和 JavaScript 语法检查，构建 Linux amd64、arm64 程序并生成 `SHA256SUMS`；上传后重新下载核验，成功才公开 Release。

已有部署可通过管理页面检测更新，或执行 `./scripts/moviehub-service.sh update`。升级前备份数据与媒体；升级会重启服务，保留原有任务、站源、JSON 配置和正式媒体文件。已完成任务的临时分片将由新版本在完整校验后自动回收。

季号与线路调整仅用于尚未发布的任务。Emby“已识别”表示已找到本地文件，实际播放权限和编码兼容性仍需在 Emby 中核对。
